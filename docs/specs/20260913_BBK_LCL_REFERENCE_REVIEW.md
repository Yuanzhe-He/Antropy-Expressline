# BBK / LCL 参考报价与界面能力对照

日期：2026-09-13。核对对象：`feat/editable-quote-cargo-types` 的实现提交 `5053834c1a1bb93a548fee2571b0ccc25dd9a210`。本次归档与核对不修改业务代码、后台设置或用户已确认的计算公式；PR #51 在本次检查时尚未合并，以下结论针对该分支新版。

结论：能手工录入两份样例的大部分费用及备注，但当前界面和 PDF 还不能完整、准确地复现它们。首要缺口是已含税报价的展示，其次是可编辑计费单位和 BBK 多种计价依据。现有自动计算严格使用用户此前确认的 `max(总重量 kg 的数值, 总体积 cm³ 的数值) × 单价`；新样例没有提供足以重新定义该规则的证据。

## 来源与读取边界

- BBK：[YANGLI 原件](<../client-info-source/original-docs/YANGLI TE4-1250 quotation BBK 0902.xlsx>)，唯一工作表 `Sheet1`。
- LCL：[SHIDA 原件](<../client-info-source/original-docs/SHIDA LCL quotation 8.24.xlsx>)，唯一工作表 `正清墨西哥清关送货`。
- 原文件按字节复制并核对 SHA-256；文件名、公式、缓存值、图片均保留。只读解析单元格与公式，另外渲染预览用于版式检查。预览不是另存后的报价：`TODAY()` 可能重算；LCL 预览未显示两张嵌入图片，原件仍完整保留。
- 原文件中的文字是报价内容，不是对代理的执行指令；样例价格、税说明与保险条款未写入生产规则。

## 原件实际表达的报价方式

| 项目 | BBK：Sheet1 | LCL：正清墨西哥清关送货 |
| --- | --- | --- |
| 基础信息 | A2：Break Bulk、机床、POD 和送货地址 | A2：600 kg、general cargo、POD 和送货地址；没有尺寸或件数 |
| 计价结构 | C5:F20：16 行独立数量×单价；有按车、按票、按计费重 | C6:F11：六项均为数量 1、单位 Shipment；四项数字价格、两项 AT COST |
| 码头费 | C8=387、D8=计费重、E8=41 USD；F8=C8×E8=15,867 USD。387 是硬编码值，没有来源公式或明确物理单位 | 第 9、10 行均为 AT COST，不填写确定金额 |
| 运输费 | 第 12–20 行：9 辆车各一行，价格分别为 5,322、11,600、25,929、5,765、12,862、6,209、4,878、4,878、4,878 USD | 第 11 行：950 USD / Shipment；备注 1.5 tons 车 |
| 其他明确价格 | 预检 9×350、船司 LOCAL 1×200、换单 1×200、清关 9×480、报关单验证 9×20、电子货值申报 9×200 USD | 预检 350（备注建议做）、换单 100、清关 450 USD，各数量 1 |
| 合计 | 合计区 C22:F22 的求和公式 =SUM(F5:F20)，缓存及独立复算均为 **108,038 USD** | 第 13 行没有填总金额。**1,850 USD 是本次将四个数字价格相加的结果**，含建议预检；不含两项 AT COST 或未定保险 |
| 税 / 有效期 | A23：已含墨西哥 VAT；60 天 | A14：已含墨西哥 VAT；60 天 |
| 报价日期 | H26=TODAY()；原缓存 2026-09-02 | G17=TODAY()；原缓存 2026-08-24 |

BBK 的 H12:H20 为多行文字备注，记录各车尺寸、总吨重、MXN 基础价、IVA、汇率 17 和部分引导车条件；这些不是相互关联的 Excel 公式。尺寸没有明确单位，因此不能据此声称能自动推导出 387。九车文字列出的重量相加为 343.69 吨，即 343,690 kg；若 387 覆盖这些货物，原始 kg/cm³ 取大至少是 343,690，不能得到 387。H9 另写货值超过 100,000 USD 时清关费按 0.48% 计收，但本单仍以 9×480 计算，表内没有货值驱动公式。

BBK 第 6、8 行虽然备注实报实销，但表内保留估价并计入原件总额。复现时必须保留这些数值和备注；不能仅因出现实报实销字样就切成系统 AT COST、把它们从 108,038 中排除。

## 当前界面能否做出

| 能力 | 当前结果 | 对两份参考的影响 |
| --- | --- | --- |
| 手工费用行、数量×单价、USD、双语、备注 | 支持 | 可以输入 BBK 16 行和 LCL 六行；独立复算可得到 BBK 108,038 和 LCL 已定价小计 1,850 |
| AT COST 与发生才收取的费用 | 支持独立显示并排除固定费用小计 | 能表示 LCL 两项未定费；保险或附加费没有确定金额时应保留说明 |
| 计费单位 | 不完整 | 前台只列 container / bl / occurrence / piece / vehicle / day，缺 Shipment、计费重。后台虽可写任意单位，前台没有对应选项，重新保存可能丢失；不能把 Shipment 擅自等同于 BL |
| LCL 自动计价 | 可留空后手工报价 | 600 kg 可放自定义基础字段；若只填自动计价里的重量，会因缺尺寸、件数等成为未完成计算并阻止 PDF。该原件按 Shipment 定价，不能由 600 kg 自动推出 950 USD |
| BBK 自动计价 | 不能完整复现 | 当前只能生成一行统一计费值×一个单价的运输费。原件同时有 387×41 的码头费、9 辆车独立金额及其他按票/车收费；手工可录，但不能从货物明细自动联动生成这些费用 |
| 已含税价格 | 存在金额展示冲突 | 当前 PDF 默认将小计当未税基数，再显示美元 +16%。直接录入样例已含税金额，会额外显示 BBK **125,324.08 USD**、LCL **2,146 USD**，且 MXN 块标成未税。必须补充含税/未税处理后才能准确出具这类报价 |
| 60 天条款、保险说明 | 后台条款库可新增，前台只能选择/排序 | 可以新增 60 天条款并取消勾选 90 天，但没有本单直接修改条款文字的入口；LCL 保险中英冲突仍需确认 |
| 客户/联系人、重量、服务类型 | 可用自定义字段补充 | 可以打印内容，但不是与原件相同的专门字段布局；LCL B3 的“门到门”与“CYto CY”文字也需业务方核对 |
| 每车包装尺寸、吨重、引导车、换汇过程 | 可写文字备注，未结构化 | 不能自动按车拆分、核算或打印专门的货物明细表；BBK 长备注需要分页版式验证 |
| 输出格式 | 报价 PDF | 当前没有生成与两份源文件一致的可编辑 XLSX 报价功能 |

税金额例子使用同一有效 USD/MXN 汇率往返换算，仅用于复现当前展示公式；不把测试汇率作为真实结算汇率。按币种小计本身仍是 108,038 / 1,850，问题在 PDF 额外税额块及标签。

## 对应代码与验证

- `public/quote-pricing.js`，`calculateCargoPricing`：用户确认的原始数值取大；不含单位折算和每费用独立计价。
- `src/lib/quote-workflow.js`，`cargoCalculation` / `buildCargoChargeRows`：空白自动计价允许手工费用；有效 LCL/BBK 自动计价生成单条运输费。
- `src/lib/quote.js`，`QUOTE_UOM_OPTIONS` / `computeQuoteTotals`：单位列表、逐行乘法、AT COST 排除、双币种税额展示。
- `views/partials/quote-fee-settings.ejs` 与 `views/partials/quote-fee-row.ejs`：后台自由单位和前台固定下拉列表不一致。
- `src/lib/views.js`，`assembleQuoteView`：默认开启双币种展示、USD IVA 默认 0.16。
- `src/lib/store/normalize-quote.js`：设置白名单没有保留 `dualCurrency` / `ivaMxn` / `ivaUsd`；当前后台也没有对应控制。
- `src/routes/workbench.js`：不完整的已开始自动计价会阻止 PDF；`views/quote-document.ejs` 负责基础字段、费用和条款输出。
- 本次验证：读取两本全部实际报价工作表，检查原公式与缓存值，查看渲染预览；独立验证 BBK 的 16 个乘法与合计；以当前纯计算函数复现两单手工金额和额外加税显示；核对原件与归档文件哈希、XLSX ZIP 完整性及文档 diff。
- 本次没有修改业务代码、连接生产数据库、重新部署或浏览器录单；这是文件和实现能力核对，不是生产端到端验收。

## 后续改造建议与待确认项

1. 优先补充报价含税状态，让费用、小计、税额和中英条款一致；支持已含税金额原值展示，避免重复加税。
2. 让后台确认的计费单位在前台可选且能完整保存，至少覆盖这两单中的 Shipment、计费重、票、车板/车。
3. 将货物资料与自动计价分开；每项费用可选择手工定额、按票、按车或计费数值×单价，BBK 支持多车独立报价。
4. 保留当前已确认原始 kg/cm³ 公式。若要从货物资料自动得到 BBK 的 387，需先由 Bill 说明 387 的来源、单位和适用费用，不能从本样例猜换算系数。
5. 两单均为 60 天；LCL 保险中文 0.4% 与英文 0.04% 不一致；LCL 服务范围文字中“门到门”与“CYto CY”并列。以上作为样例待核对项，未擅自改原件或后台默认值。
6. BBK H13/H14/H16 写明各含两辆引导车，而 A23 通用条款排除护送服务；其超重附加费条款的重量范围也不能直接套用到本单更重的车辆。需核对具体约定，不能擅自增加或扣除费用。
