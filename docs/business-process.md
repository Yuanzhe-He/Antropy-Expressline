# 业务流程与口径

## 1. 产品边界

系统当前按三个模块拆分：

- `换单`
- `清关`
- `陆运`

其中本期已实现的业务口径：

- `换单` 可单独报价
- `清关` 可单独报价
- 某些票会同时有 `换单 + 清关`
- 当一票业务同时包含 `换单 + 清关` 时，系统将其视为连续业务
- `落柜` 被纳入 `清关` 模块
- `码头费` 也被纳入 `清关` 同页计算，不再单独拆一个前台页面

## 2. 换单模块

### 前台输入

- 船公司
- 业务性质
- 提单数，默认 `1`
- 混装柜型与数量
- demoras 天数
- 汇总币种
- 税前 / 税后显示
- 各费用项税率覆盖

### 前台输出

- 计算公式
- 解释
- `cargos locales`
- `garantia`
- `demoras`
- 总数
- 是否只能给客户 / 收货人开发票
- `corte de demoras` 谁能做

### 后台维护

- 船公司表
- 每家船公司的柜型
- `cargos locales`
- `garantia`
- `demoras`
- 发票规则
- `corte de demoras`
- 默认税率
- demoras 阶梯支持在后台新增 / 删除

## 3. 清关模块

### 总体逻辑

清关模块是一个一页式流程，包含：

- 码头固定费
- 码头堆存费
- 落柜
- 清关堆场费

### 前台输入

- 业务性质
- 港口
- 码头
- 船公司
- 场站
- 混装柜型与数量
- 天数
- 汇总币种
- 税前 / 税后显示
- 各费用项税率覆盖

### 前台输出

- 各费用项公式
- 各费用项解释
- 各费用项税前 / 税后金额
- 总数
- 当前选择的港口 / 码头 / 场站

### 后台维护

- 船公司与场站映射
- 港口
- 码头
- 场站
- 码头固定费
- 码头堆存费阶梯
- 落柜费
- 清关堆场费
- 默认税率
- 币种
- 码头堆存阶梯支持在后台新增 / 删除

## 4. 场站与船公司关系

### 业务口径

- 场站取决于 `港口 + 船公司`
- 一个港口下可以有多个码头
- 一个场站可以关联多个港口
- 一个场站可以关联多个船公司
- 一个 `港口 + 船公司` 组合也可能对应多个场站

### 当前实现

- 前台先选 `港口 + 船公司`
- 系统自动筛出可用场站列表
- 前台再选择具体场站
- 后台同时维护：
  - 船公司视角的场站映射
  - 场站视角的船公司映射

保存时系统会把两边映射合并，避免只维护一边。

## 5. 费用计算规则

### 5.1 固定费用

固定费用按“柜”计算。

例如：

- `20GP x 3`
- `40HQ x 2`

系统会分别读取各柜型单价，再乘数量后汇总。

### 5.2 可变费用 / 堆存费

堆存费是按天、按阶梯、按箱型累进计算。

示例：

- `0-7 天：0`
- `8-10 天：115`
- `11-30 天：200`

如果输入 `20 天`，则系统会按各区间逐段累计，而不是只取最后命中的一个区间。

### 5.3 免费天

免费天不单独做一个字段，而是通过：

- 区间金额 = `0`

来表示。

## 6. 天数口径

### 行业资料

根据官方资料，行业里并不存在一个跨所有港口、所有码头、所有船公司的统一“第 0 天 / 第 1 天”口径，实际起算点经常由承运人或具体 terminal tariff 决定。

参考：

- FMC：`demurrage accrues when a container exceeds free time on a marine terminal`
  - https://www.fmc.gov/detention-and-demurrage/
- FMC 审计最佳实践：货物可提状态日期不应简单等于船到港日期，除非货物当天实际可提
  - https://www.fmc.gov/databases-and-publications/vessel-operating-common-carrier-vocc-audit-program/
- Maersk 美国进口信息：free time 的起算点随 terminal 而异，常见写法是“集装箱卸船后的下一个业务时点开始”
  - https://www.maersk.com/zh-cn/local-information/north-america/united-states-of-america/import
- Maersk 条款：Demurrage 针对的是 free time 之外，货柜仍留在 terminal / port / depot 内的时间
  - https://terms.maersk.com/dnd

### 系统实现口径

为了防错和便于录入，当前系统采用下面的产品口径：

- 前台允许从 `0` 天开始输入
- 后台阶梯按顺序维护
- 免费段可以显示为 `0-7`
- 系统会自动顺延下一段的起始日
- 后台用户只需要维护：
  - 当前段的结束日
  - 金额
  - 币种
  - 税率

这样做的目的不是宣称行业统一从 `0` 计费，而是为了：

- 避免区间重叠
- 避免人工把 `6-8`、`8-10` 这种规则输错
- 让演示和报价操作更稳定

## 7. 税率与汇率

### 汇率

- 当前仅支持 `USD / MXN`
- 不同费用项可有不同币种
- 汇总时统一换算到前台选择的汇总币种

### 税率

- 后台给每项费用配置默认税率
- 前台可以临时覆盖税率
- 当前税率预设默认包含：
  - `0%`
  - `16%`

## 8. 连续业务

### 定义

业务性质包含：

- `仅换单`
- `仅清关`
- `换单 + 清关连续业务`

### 当前实现

如果前台在换单页选择：

- `换单 + 清关连续业务`

那么换单计算后，系统会把以下上下文带到清关页：

- 船公司
- 柜型
- 数量
- 汇总币种
- 税前 / 税后显示

这让同一票业务可以连续处理，而不需要再次全部录入。

## 9. 当前已确认但尚未完全产品化的点

- 清关堆存阶梯当前可编辑现有行，但还没有可视化新增 / 删除阶梯行
- 数据持久化仍是 JSON 文件
- 账号权限目前暂时关闭，所有访问者都可进入前台和后台修改规则
